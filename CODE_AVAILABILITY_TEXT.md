# Suggested Code availability wording

## If the GitHub repository has been made public before submission

Custom scripts used to reproduce the neuPrint connectivity analyses and MaleCNS mesh-proximity analyses are available at https://github.com/szac74/SIFa-connectome-analysis. The repository includes the SIFa neuron identifiers, analysis parameters, grouping rules, and metadata for the representative MaleCNS sites shown in Fig. 7.

## If the repository is ready but kept private during initial submission

Custom scripts used to reproduce the neuPrint connectivity analyses and MaleCNS mesh-proximity analyses are available to editors and reviewers via a private repository link provided at submission. The code will be deposited in a persistent public repository upon publication.

## Important

Do not state that this repository contains the original archived analysis script. The original connectome analysis was performed interactively using custom neuPrint/Cypher queries and stepwise Python analyses; this repository consolidates the final analysis logic into reproducible scripts.
